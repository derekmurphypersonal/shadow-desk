Original to this project (generated by scripts in `tools/`): advisor portraits, voice recordings, UI icons, emblem, music, sound effects. All advisors are fictional people: portraits were generated from written descriptions, never from photographs or names of real people. Event writing and game design are original. Lines without a recording fall back to the player's operating-system text-to-speech voices.
